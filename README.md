## Final Project – Arpeggiated Musical Controller

- Expands on my earlier Arduino ↔ p5.js arpeggiator system
- p5.js reads keyboard input and sends commands to the Arduino via serial
- Arduino generates musical notes and arpeggiated patterns based on major/minor scales
- Original piezo buzzer output is upgraded to a real speaker with an amplifier for louder, clearer audio
- Includes improved BPM control and cleaner mode switching between major and minor arpeggios
- Provides a more responsive, expressive musical interaction using both software and hardware
